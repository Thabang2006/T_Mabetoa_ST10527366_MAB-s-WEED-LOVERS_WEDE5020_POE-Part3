MAB's WEED LOVERS — Website Project

HOW TO RUN
1. Extract this ZIP file.
2. Open the MAB's WEED LOVERS folder.
3. Open index.html in a modern browser.

FEATURES
- Responsive navigation with mobile menu
- Shared external CSS stylesheet
- JavaScript active-page navigation state
- Gallery category filters and image lightbox
- Contact form browser validation and demo status message
- Automatically updated copyright year

IMPORTANT
This is a front-end demonstration. The contact form does not send or store data. No checkout, ordering, or sales functionality is included.
